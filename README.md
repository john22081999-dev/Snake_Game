# Snake Game

A classic Snake game built in Python using the turtle graphics library.

## Features

- Arrow-key controls to steer the snake
- Snake grows each time it eats food
- Live score display, with the high score saved between sessions
- Game-over detection on wall and tail collisions

## Built with

- Python 3
- turtle (graphics)
- Object-oriented design: separate Snake, Food and Scoreboard classes

## How to run

Run the main file: `python main.py`

(turtle comes built into Python, so there is nothing extra to install.)
